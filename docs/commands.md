# Commands

Everything in Shadowbound can be set in the options window (`/shadow`). These chat commands are shortcuts.

`/shadowbound` works everywhere `/shadow` does. Commands only do something on a rogue.

## Windows and help

| Command | What it does |
| --- | --- |
| `/shadow` | Opens or closes the options window. `/shadow options` and `/shadow config` do the same. |
| `/shadow help` | Lists every command in chat. |

## Frames

| Command | What it does |
| --- | --- |
| `/shadow unlock` | Unlocks all frames so you can drag and resize them. See [Frames and minimap](features/frames-and-minimap.html). |
| `/shadow lock` | Locks the frames again. |
| `/shadow move` | Unlocks the frames, or locks them if they are unlocked. |
| `/shadow reset` | Puts every frame back in its default place and size. |
| `/shadow grid` | Turns snapping to the grid on or off. |
| `/shadow grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/shadow minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/shadow explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Each command also works without the space, for example `/shadowunlock` or `/shadowreset`. That helps with chat setups that swallow the Enter key after a space.

Type anything else after `/shadow` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/shadow`.
